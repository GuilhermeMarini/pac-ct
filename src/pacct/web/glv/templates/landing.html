Visualizador de Lógica

Escolha um RDB do projeto para listar os relés e marcar os GLE. Dá para abrir vários de uma vez, de relés diferentes. Cada diagrama abre desconectado, numa aba própria; conectar é um botão lá dentro.

O diagrama abre desconectado
Os valores ficam indeterminados até você clicar em Conectar no cabeçalho. Vários diagramas podem ficar abertos ao mesmo tempo, cada um com o seu relé; dois no mesmo IP dividem uma única sessão telnet.
Como ler o relé — escolha na linha de cada um
Telnet (Fast Message) — lê a Relay Word inteira, mas nunca vê Virtual Bits nem páginas de GOOSE.
MMS (IEC 61850) — não gasta sessão telnet, mostra as páginas de GOOSE e todas as Virtual Bits, mas não alcança todos os bits (a Relay Word inteira só o telnet lê).
Notas
1O IP vem do próprio RDB quando está lá. Se não estiver, preencha antes de plotar — sem IP não há telnet, e sem telnet não há estado ao vivo.
2O modo visualização renderiza o GLE sem conectar: todos os bits ficam indeterminados. Serve para conferir a lógica quando o relé não está acessível.
3O banner de login é drenado antes de entregar o socket à biblioteca. Relés 3xx anunciam nome, data, estação e modelo — quatro linhas que estouravam as cinco tentativas da verificação e derrubavam a conexão.
4Marque vários GLE — de relés diferentes, se quiser — e abra todos de uma vez. O lote é conferido inteiro antes de abrir: um IP faltando barra o lote todo, em vez de abrir metade dele.
5Esta ferramenta é compartilhada: fala com um relé físico por vez, então todos os visitantes veem o mesmo diagrama. Trocar GLE derruba a sessão de todo mundo.
